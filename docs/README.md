# Spherosphere documentation

These documents form the maintained documentation set. Start
with the [user README](../README.md) for installation and the
basic GUI enrollment sequence.

| Document | Purpose |
|---|---|
| [GUIDE](GUIDE.md) | GUI use, enrollment, adapter profiles, service installation, migration, and troubleshooting. |
| [TECH](TECH.md) | Software architecture, API, identity/state ownership, transports, reliability, development, and future work. |
| [PROTOCOL](PROTOCOL.md) | GATT and Mesh messages, models, datapoints, exact vectors, and device behavior. |
| [FIRMWARE](FIRMWARE.md) | Original summary of processor, device behavior, and custom-content limits. |
| [REPORT](REPORT.md) | The investigation narrative and how the findings relate. |
| [STATUS](STATUS.md) | Current handoff, recorded host observations, outstanding questions, and next work. |

Canonical documents reference each other and primary source
material. Technical claims distinguish source-code behavior,
static image analysis, authenticated device replies, visible
observations, and inference.

Private working notes and original research artifacts are not
part of the published documentation. The maintained documents
contain original explanations of behavior and protocol facts.
